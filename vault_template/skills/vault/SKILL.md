# vault

## Remembering

1. Decide where it belongs:
   - a quick fact, idea or thing to do later → a new dated note in `raw/`, `raw/YYYY-MM-DD-<short-topic>.md`;
   - lasting knowledge about an existing topic → append to that note in `wiki/`, found with Grep first.
2. Write it in the owner's words and language, with the date. Link people, projects and topics as `[[name]]`.
3. Reply in one sentence: what you saved and where.

## Recalling

1. Grep the vault for the key words, in every spelling the owner might have used (Uzbek, Russian, English).
2. Read the matching notes, newest first.
3. Answer in one to three sentences, naming the note it came from. If nothing matches, say so and offer to remember
   it now.
