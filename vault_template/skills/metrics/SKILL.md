# metrics

The numbers live in `wiki/metrics.md`, one table per metric, newest row last:

```
# Metrics

## YouTube subscribers

| Date | Value | Note |
|---|---|---|
| 2026-09-24 | 135000 | |
```

## Recording

When the owner states a number, add a row with today's date to that metric's table, creating the table or the file
if needed. Never change an old row. Confirm in one sentence with the change since the previous row.

## Reporting

Read `wiki/metrics.md` and say the latest value of each metric asked about, with the change since the previous row
and the date it was recorded. If a goal is written next to a metric, say how far there is to go.

No platform is connected yet: numbers come only from what the owner has told you. If a number is older than a week,
say how old it is.
