# trends

1. Take the period the owner names, or the last seven days.
2. From `wiki/metrics.md`: for each metric with rows in the period, the change from the first to the last value.
3. From the notes: which `wiki/` topics and `raw/` notes were created or edited in the period (Glob by date in the
   name, Grep for dates), and which plans in `outputs/` were carried over more than once.
4. Write `outputs/YYYY-MM-DD-trends.md` with the numbers and the topics, linking each source note.
5. Say the two or three biggest changes in at most three sentences.

Outside trends — news, search, social platforms — are not connected yet. Say so if asked.
